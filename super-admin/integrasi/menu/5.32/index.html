API ini hanya membaca data (GET) dan selalu membalas JSON UTF-8. Setiap aplikasi memakai kuncinya sendiri, dengan scope, museum, batas laju, dan masa berlaku yang diatur di tab Klien API. Sesi dan cookie tidak dipakai.

Autentikasi

Kirim kunci di header Authorization dengan skema Bearer pada setiap permintaan. Kunci berbentuk smk_ diikuti 8 karakter awalan dan 43 karakter rahasia.

curl -H "Authorization: Bearer $SIMAKO_KUNCI" \
     "/simako-update/super-admin/api/v1/koleksi?museum_id=1&per_halaman=20"
  • Kunci tampil sekali saat klien dibuat atau kunci diputar. SIMAKO hanya menyimpan hash dan awalannya.
  • Simpan kunci di server aplikasi, misalnya variabel lingkungan. Jangan menaruhnya di kode yang dikirim ke peramban kecuali halaman itu memang publik dan asalnya didaftarkan untuk CORS.
  • Bila kunci bocor atau hilang, putar kunci di tab Klien API. Kunci lama langsung ditolak.
  • Kunci tidak bisa dikirim lewat parameter URL.
Scope dan museum

Scope menentukan endpoint yang boleh dipanggil. Semua scope hanya membaca. Data selalu dibatasi pada museum yang dipilih untuk klien, dan batas ini diperiksa di server.

ScopeNamaIsi
koleksiKoleksiData publik koleksi aktif: nomor, nama, jenis, bahan, dimensi, narasi.
museumMuseumProfil museum yang diizinkan: alamat, kontak, situs web, jumlah koleksi.
pameranPameran publikPameran yang sudah disetujui dan aktif, beserta daftar koleksinya.
lokasiLokasi ringkasJumlah koleksi per gedung. Lantai, ruang, dan rak tidak dibuka.
  • Parameter museum_id di luar daftar museum klien dijawab 403 museum_tidak_diizinkan.
  • Koleksi atau pameran milik museum lain dijawab 404 tidak_ditemukan, sama seperti data yang tidak ada.
  • Yang tidak pernah dibuka: harga, cara dan asal perolehan, kondisi dan catatan kondisi, keterangan dan catatan lapangan, lantai, ruang, rak, dan kotak penyimpanan, nomor BMN, serta nama dan akun pengguna SIMAKO. Koleksi yang dihapus atau sedang menunggu penghapusan tidak ikut.

Paginasi

Semua endpoint daftar memakai halaman (mulai 1) dan per_halaman (1 sampai 100, bawaan 20). Jumlah data ada di meta.total, alamat halaman berikut dan sebelumnya ada di tautan.berikut dan tautan.sebelum (bernilai null di ujung daftar).

Batas laju

Setiap klien punya batas permintaan per menit. Setiap respons untuk kunci sah membawa header berikut. Bila batas terlampaui, API membalas 429 dan header Retry-After berisi jumlah detik sampai menit berikutnya.

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 57
X-RateLimit-Reset: 1792866180
Retry-After: 42

X-RateLimit-Reset adalah waktu Unix (detik) saat hitungan dimulai lagi. Retry-After hanya ada pada respons 429.

CORS

CORS mati secara bawaan, jadi halaman web di peramban tidak bisa membaca respons API. Bila sebuah situs publik perlu memanggil API langsung dari peramban, daftarkan asalnya (mis. https://portal.contoh.go.id) pada klien. Permintaan peramban dengan asal lain ditolak 403 asal_tidak_diizinkan. Panggilan dari server tidak membawa header Origin dan tidak terpengaruh.

Kode galat

Galat selalu berbentuk sama:

{
  "galat": {
    "kode": "scope_tidak_diizinkan",
    "pesan": "Kunci ini tidak punya scope pameran (Pameran publik). Minta pengelola SIMAKO menambahkannya.",
    "status": 403
  }
}

Setiap permintaan, termasuk yang ditolak, tercatat di tab Log permintaan beserta awalan kunci, IP, dan aplikasi pemanggil. Kunci utuh tidak pernah dicatat.

Kunci API baru

Kunci untuk . Salin dan kirim ke penanggung jawab klien lewat saluran yang aman.

Kunci ini hanya tampil sekali. Setelah jendela ini ditutup, SIMAKO hanya menyimpan hash dan awalannya, jadi kunci tidak bisa dilihat lagi. Bila hilang, putar kunci untuk membuat yang baru.

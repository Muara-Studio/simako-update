Setiap skenario di bawah dijalankan otomatis oleh Playwright terhadap SIMAKO purwarupa di PHP 8.3.36 (lingkungan staging lokal, data contoh), setelah perbaikan seluruh cacat temuan putaran pertama, masuk sebagai akun nyata dari tiap peran. Pembaruan 25 Oktober 2026

Perubahan sesudah UAT 24 Oktober. UAT belum diulang untuk perubahan ini.

  • Menu API dan Integrasi (Master 5.32). Admin membuat kunci API per instansi, membatasi museum yang boleh dibaca, dan melihat siapa memakai API dan kapan. API hanya membaca data publik museum, koleksi, pameran, dan lokasi.
  • Tampilan. Breadcrumb ganda dihapus, panel notifikasi lebih lebar, daftar User Management dan Menu Management lebih rapat, kartu panduan lebih lega, dan rincian pengguna dikelompokkan.
  • Data koleksi produksi. Salinan uji sekarang memakai ekspor koleksi produksi: 229.024 koleksi dari 14 museum, dirapikan per museum. Setiap museum menerima daftar data yang perlu dicek, misalnya nomor registrasi ganda dan kondisi teks bebas.
  • Kinerja. Halaman yang membaca koleksi diuji dengan volume produksi. Tiga halaman yang sebelumnya gagal karena memori sekarang berjalan, laporan koleksi dua kali lebih cepat, dan indeks basis data baru ikut di paket rilis.
  • Foto koleksi. Foto yang sudah ada di server tetap terpakai setelah naik versi. Panduan memindahkan foto ke salinan lain sudah disiapkan. Foto hanya tampil untuk pengguna yang masuk.
  • Paket rilis. Paket untuk server Pusdatin di PHP 8.3.36 sudah dibuat ulang, lengkap dengan panduan deploy dan migrasi basis data.

Versi publik halaman ini tidak memuat tangkapan layar dan rincian teknis keamanan.
